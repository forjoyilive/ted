# Clarify

## Goal

Remove ambiguity before Design, so the rest of the Workflow builds the right thing.

## Skip when

The Task is already clear: a small, specific change with one obvious reading. Post a one-line note saying Clarify had nothing to ask, then report the outcome.

## Steps

1. Check the Task’s size first. If it won’t fit in one pull request per repo, say so in a note, explain where you would split it, and wait for the human.
2. Pick a depth and post it with your reason in one line:
   - **None** when nothing is unclear.
   - **Few** when a handful of simple questions would settle it. Ask them all in one note.
   - **Grilling** when the Task hides real decisions. Ask in rounds, one note per round, and finish with a note summarizing what was decided.
3. Wait for the human’s answers before you go on.

## Done when

Every question you asked has an answer, and for grilling, the summary is posted. Then report the outcome.

## Ask the human when

Any answer raises something bigger than the question it answered. Switch to grilling and say so.
