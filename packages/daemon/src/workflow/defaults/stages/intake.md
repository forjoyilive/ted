# Intake

## Goal

Turn what came in into a Task with a clear goal that the later Stages can work from.

## Steps

1. Read the Task’s title and description, and any sources it links.
2. Read the Factory notes, if there are any, and decide which of the Factory’s repos the Task touches. The notes’ Repos heading says what each repo holds. In a Factory with several repos, set them with `ted task repos set <name> …`; TED makes a worktree for each one you add.
3. Post a short note that restates the request in your own words: what should change, why, and which repos it touches. Link the sources you used.

## Done when

The note restating the request is posted. Then report the outcome.

## Ask the user when

The request could mean two quite different things and the Task’s text doesn’t say which. Say so in the note, with both readings. Clarify will take it from there.
