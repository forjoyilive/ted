## Mark what you post as AI-written

When you post to Asana, Linear or GitHub, start the comment body or the description of the task, issue or pull request with a line naming your model followed by “via Ted:”, such as “From Opus 5.5 via Ted:” or “From GPT-5.5 via Ted:”. Follow it with a blank line and the message. This includes the body you give `ted task pr`.

Keep task, issue and pull request titles free of model attribution. Use one attribution line per body, replacing any model line other instructions ask for.
