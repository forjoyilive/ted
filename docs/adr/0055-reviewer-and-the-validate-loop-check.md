# The reviewer and the loop check are sub-agents chosen by Ted; the loop ask holds the send-back

**The reviewer.** The Task Lead starts the reviewer with `ted run start --reviewer --prompt-file <file>`. It is an ordinary sub-agent (ADR 0049) named “Reviewer · <Stage>”, but Ted picks its agent, model and effort, and `--agent`, `--model` and `--effort` are refused with it. An explicit `reviewer` setting is used as written: Ted refreshes that agent’s health first, and if it can’t run, the request waits in the queue like any paused Run, with no fallback. An unset `reviewer` takes the other kind from the Task Lead when that kind is installed, has no pause and passes its health check, else the Task Lead’s kind. `v1.ReviewerChosen` records the choice and the kind that was unavailable, keyed by the Run ID. The choice is made when the reviewer is requested, which is during Validate, not at the moment Validate starts.

**The Validate event.** At Validate, `ted outcome advance` and `ted outcome back` take `--review pass|fail`, `--review-notes <n>`, `--visual pass|fail` and `--visual-notes <n>`. Every advance or back the Task Lead reports from Validate records `v1.ValidateJudged` with the visit’s last Check run, the review and visual results, and the reviewer from `v1.ReviewerChosen`. When a reviewer ran and the Task Lead says nothing about the review, an advance counts it as passed. The thread shows a passed one as “Validate passed · Reviewed by Claude (Codex unavailable)” carrying the ✓ row; a sent-back one adds the same to the next send-back line. The ✓ row draws Review and Visual after the Checks (“✓ Review · 2 notes”), and the Review sign-off card draws the row of the last “Validate passed” before it, under its title.

**The loop check.** When Validate’s counted send-back would be round `loop_check`, Ted doesn’t record it yet. It starts a sub-agent of the Task Lead named “Loop check · Validate”, with the reviewer’s agent, model and effort, and with instructions from Ted (`workflow/defaults/loop-check.md`): each round’s Findings and the commit the primary worktree was at when each round sent the Task back. Ted finds those commits with `git rev-list -1 --before=<send-back time> HEAD`, so no send-back event had to change. `v1.LoopCheckStarted` holds the pending send-back; `v1.LoopCheckFinished` holds the verdict, read from the last “Verdict: converging|looping” line. Converging records the send-back and moves the Task to Work with the verdict added to the Task Lead’s instructions. Looping, no verdict, or a loop check that never ran to the end asks the human. A daemon restart waits on unfinished loop checks again. While one is pending, `ted outcome advance` and `back` are refused.

**The ask.** Over Validate’s `max_back`, or after a looping verdict, Ted posts a `question` listing each round’s blocking Findings, with **Try again**, **Back to Design** (only when Design is on and before Validate) and **Move to <next Stage> anyway**. `v1.SendBackAsked` keys the held send-back by the question’s Comment ID; other Stages’ over-limit questions are recorded the same way, with `loop: false`. While any such question is open in the Task’s Stage, `ted outcome advance` and `back` are refused, which fixes the Task Lead moving on past an unanswered limit question. Any answer resets Validate’s count, as before. Try again records the held send-back as round 1 and moves to its Stage. Back to Design records an uncounted send-back to Design. Move on anyway moves to the next Stage and tells the Task Lead to put the open Findings in the brief. Words alone go to the Task Lead and the Task stays.

## Considered Options

- **Ted starting the reviewer on its own at Validate entry.** Rejected: the Task Lead writes the reviewer’s prompt from the Design brief and the diff, and decides how to use its Findings. Ted only decides which agent it is.
- **Recording each send-back’s commit in a new `v3.TaskSentBack`.** Rejected for now: the commit times give the same answer for local commits, and the send-back tables stay as they are.
- **Treating a loop check that fails as converging.** Rejected: asking the human is the safe default when Ted can’t tell.
