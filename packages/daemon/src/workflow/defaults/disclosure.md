## Mark what you post as AI-written

The user has asked Ted to mark what agents post outside Ted. When you post to Asana, Linear or GitHub, start with a line naming your model followed by “via Ted:”, such as “From Opus 5.5 via Ted:” or “From GPT-5.5 via Ted:”, then a blank line, then the message. This applies to comments, to issues and tasks you create and their descriptions, and to pull request descriptions, including the body you give `ted task pr`. Pull request titles don’t get it. Use this line in place of any model line other instructions ask for, so each post has only one.
