# Contributing to Ted

## Issues

Bug reports are welcome. Open an [issue](https://github.com/forjoyilive/ted/issues) and say what happened and what you expected. Ted’s **Report a problem** menu item copies a diagnostic report you can paste in; read it before posting.

## Discussions

Questions, feature ideas and anything else go in [Discussions](https://github.com/forjoyilive/ted/discussions): [Q&A](https://github.com/forjoyilive/ted/discussions/categories/q-a) for how to do something, [Ideas](https://github.com/forjoyilive/ted/discussions/categories/ideas) for what Ted should do next, and [Show and tell](https://github.com/forjoyilive/ted/discussions/categories/show-and-tell) for the factories you’ve built.

## Pull requests

Ted doesn’t accept pull requests for now, and closes them without review. Kriya Design LLC owns all of Ted’s code, and keeping it that way lets it change how Ted is licensed or run in the future. If you have a fix, describe it in an issue instead.
