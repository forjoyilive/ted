# Contributing to Ted

## Issues

Bug reports and feature requests are welcome. Open an [issue](https://github.com/forjoyilive/ted/issues) and say what happened and what you expected. For a bug, Ted’s **Report a problem** menu item copies a diagnostic report you can paste in; read it before posting.

## Pull requests

Ted doesn’t accept pull requests for now, and closes them without review. Kriya Design LLC owns all of Ted’s code, and keeping it that way lets it change how Ted is licensed or run in the future. If you have a fix, describe it in an issue instead.
